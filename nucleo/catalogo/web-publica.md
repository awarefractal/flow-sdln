# Web pública

## SEO técnico
- **Pregunta:** ¿qué señales mínimas debe cumplir cada página?
- **Opciones comunes:** un solo `h1`; `title` y `description` únicos; canonical absoluto; `og:image`; `alt` en toda imagen; sitemap; robots; datos estructurados (JSON-LD).
- **Costo de decidir tarde:** bajo
- **Fuentes sugeridas:** Google Search Central; schema.org.

## GEO (visibilidad en motores de respuesta con IA)
- **Pregunta:** ¿cómo se hace el contenido encontrable y citable por asistentes de IA?
- **Opciones comunes:** política explícita de robots para rastreadores de IA; contenido en texto con respuestas directas; datos estructurados; propuestas como `llms.txt`.
- **Costo de decidir tarde:** bajo
- **Fuentes sugeridas:** no hay un estándar consolidado; investigar el estado actual cada vez y verificar la adopción real de cada propuesta.

## Rendimiento web
- **Pregunta:** ¿qué presupuesto de carga se acepta?
- **Opciones comunes:** objetivos de Core Web Vitals; imágenes optimizadas; JavaScript mínimo.
- **Costo de decidir tarde:** bajo
- **Fuentes sugeridas:** web.dev (Core Web Vitals).

## Analítica y consentimiento
- **Pregunta:** ¿qué se mide y con qué consentimiento?
- **Opciones comunes:** analítica sin cookies; banner con rechazo tan fácil como aceptar.
- **Costo de decidir tarde:** bajo

## Contenido y navegación
- **Pregunta:** ¿cómo se estructura el contenido para que personas y buscadores lo recorran?
- **Opciones comunes:** jerarquía clara de páginas; enlaces internos; migas de pan.
- **Costo de decidir tarde:** bajo

## Cabeceras de seguridad
- **Pregunta:** ¿qué políticas de seguridad envía el servidor?
- **Opciones comunes:** CSP, HSTS, política de referrer y de permisos.
- **Costo de decidir tarde:** bajo
- **Fuentes sugeridas:** OWASP Secure Headers Project.
